# Как выложить «Электроосмотр» на GitHub, открыть по ссылке и установить на телефон

Инструкция на 10 минут. Нужен только браузер, устанавливать программы не надо.
В конце получится ссылка вида `https://ваш-логин.github.io/electroosmotr/`, которую можно отправлять кому угодно,
и приложение можно будет установить на телефон как обычное.

---

## Шаг 0. Что лежит в папке

```
index.html              ← приложение
manifest.webmanifest    ← описание приложения для установки
sw.js                   ← офлайн-режим (service worker)
icons/                  ← иконки: 192, 512, maskable, apple-touch, favicon
vendor/jszip.min.js     ← библиотека ZIP
vendor/xlsx.full.min.js ← библиотека Excel
README.md               ← описание для страницы репозитория
ИНСТРУКЦИЯ.md           ← этот файл
.nojekyll               ← технический файл, необязательный
```

Загружать нужно **всё содержимое** папки, сохраняя структуру: папки `icons` и `vendor` должны лежать рядом с `index.html`.
Без `manifest.webmanifest`, `sw.js` и папки `icons` приложение работает, но установка и офлайн-режим не появятся.

---

## Шаг 1. Создайте репозиторий

1. Зайдите на [github.com](https://github.com) и войдите в аккаунт.
2. Нажмите **зелёную кнопку «+»** справа вверху → **New repository**.
3. Заполните:
   - **Repository name**: `electroosmotr` (латиницей, без пробелов — можно любое другое имя);
   - выберите **Public** — для бесплатного GitHub Pages репозиторий должен быть публичным;
   - галочки `Add a README file`, `.gitignore`, `license` **не ставьте**.
4. Нажмите **Create repository**.

---

## Шаг 2. Загрузите файлы

1. На странице репозитория нажмите **Add file → Upload files**.
2. Откройте на компьютере папку `github-pages` и **перетащите в браузер всё её содержимое**:
   `index.html`, `manifest.webmanifest`, `sw.js`, `README.md`, `ИНСТРУКЦИЯ.md`,
   а также **папки `icons` и `vendor`**.
   - Перетаскивать нужно файлы и папки, а не саму папку `github-pages`.
   - Если папки не переносятся: сначала загрузите файлы и нажмите **Commit changes**,
     затем ещё раз **Add file → Upload files** и перетащите папки `icons` и `vendor` по одной.
     Внутри них файлы должны остаться в своих папках.
3. Дождитесь, пока список загрузится, и нажмите **Commit changes**.

> Файл `.nojekyll` может быть невидимым в проводнике — он необязателен, без него всё работает.
> Если нужен: **Add file → Create new file**, имя `.nojekyll`, содержимое пустое, **Commit changes**.

---

## Шаг 3. Включите GitHub Pages

1. В репозитории откройте вкладку **Settings**.
2. В левом меню выберите **Pages**.
3. В блоке **Build and deployment**:
   - **Source**: `Deploy from a branch`;
   - **Branch**: `main` и папка `/ (root)`;
   - нажмите **Save**.
4. Подождите 1–2 минуты и обновите страницу.
   Появится надпись **«Your site is live at https://<логин>.github.io/<репозиторий>/»**.
5. Откройте ссылку — приложение должно появиться.

---

## Шаг 4. Проверьте на телефоне

1. Откройте ссылку **в Chrome** (Android) или **в Safari** (iPhone).
   Не из Telegram, VK или почты — их встроенные браузеры часто блокируют камеру.
2. «Начать осмотр» → заполните параметры → «Начать осмотр».
3. «Снимок» → браузер спросит доступ к камере → **Разрешить**.
4. Должно открыться живое превью. Снимайте сколько нужно: счётчик растёт, миниатюры появляются внизу.
5. Закройте камеру крестиком — фото останутся в осмотре.
6. «Выгрузить отчёт» → «Сформировать» — скачается ZIP с Excel и папками фото.

---

## Шаг 5. Установите приложение на телефон

Установка возможна только по ссылке `https://`. Приложение ведёт себя как обычное: иконка на главном экране,
запуск без адресной строки, работает без интернета.

**Android, Chrome**
1. Откройте ссылку.
2. На стартовом экране появится карточка **«Установка»** с кнопкой **«Установить приложение»** — нажмите её.
3. Либо: меню браузера **⋮ → «Установить приложение»** (может называться «Добавить на главный экран»).
4. Подтвердите — иконка появится на главном экране.

**Android, Яндекс Браузер**
Кнопка установки может не появиться (браузер не отдаёт системное окно установки) — тогда на карточке будет
подсказка: меню **⋮ → «Установить приложение»** или «Добавить на главный экран».

**iPhone, Safari**
Кнопки нет — это ограничение iOS. Нажмите **«Поделиться»** (квадрат со стрелкой) → **«На экран „Домой“»** → «Добавить».

После установки приложение открывается с иконки, без адресной строки, и работает без сети.
Повторно устанавливать при обновлении не нужно — обновится само.

---

## Шаг 6. Раздайте ссылку

Скопируйте адрес из строки «Your site is live at …» и отправьте сотрудникам.

- Устанавливать ничего не нужно: достаточно открыть ссылку в браузере.
- У каждого пользователя свои данные: фото хранятся в его браузере и попадают только в его архив.
- На сервере GitHub лежит лишь сам файл приложения, никаких фотографий.

---

## Как обновить приложение

1. Откройте репозиторий → **Add file → Upload files**.
2. Перетащите новый `index.html` (при необходимости — другие изменённые файлы).
3. **Commit changes** и подождите 1–2 минуты, пока GitHub Pages пересоберётся.

**Важно про офлайн-кэш.** Приложение запоминает файлы, чтобы работать без сети. Обычно страница
обновляется сама при следующем открытии. Если поменялись `index.html`, файлы в `vendor/` или иконки:

1. Откройте `sw.js` → значок карандаша.
2. Найдите строку `const CACHE = 'elektroosmotr-v1';`
3. Поменяйте версию: `'elektroosmotr-v2'` (потом `v3`, `v4` …).
4. **Commit changes**.

Пользователям, у которых приложение уже установлено, нужно **полностью закрыть** его (свайп из списка
недавних приложений) и открыть заново — тогда подтянется новая версия. Иногда достаточно обновить страницу
потягиванием вниз.

## Если что-то не работает

| Что видно | Что делать |
|---|---|
| «404 There isn't a GitHub Pages site here» | Pages ещё собирается (подождите 2 минуты) или в Settings → Pages не нажали Save |
| Открывается список файлов вместо приложения | `index.html` лежит не в корне репозитория — переместите его в корень |
| «Живое превью недоступно» | Открыто не по https, либо браузер запретил камеру: значок замка → Разрешения → Камера → Разрешить → перезагрузить |
| Камера не запускается только в Telegram/VK | Откройте ссылку в Chrome: меню «⋮» → «Открыть в браузере» |
| Нет карточки «Установка» | Ссылка не `https://`, приложение уже установлено, или браузер не поддерживает — используйте меню ⋮ → «Установить приложение» |
| Иконка на главном экране без картинки | Не загрузилась папка `icons` — проверьте, что в репозитории есть `icons/icon-192.png` |
| После обновления остался старый вид | Не поднята версия в `sw.js` или приложение открыто из кэша: закройте его полностью и откройте снова |
| Отчёт не скачивается | Проверьте, что в браузере разрешены загрузки и есть свободное место |
| «Нет доступа к библиотекам ZIP/XLSX» | Не загружена папка `vendor` и нет интернета — загрузите `vendor` |

## Частые вопросы

**Ссылка публичная?**
Да. Сайт на GitHub Pages виден всем, у кого есть адрес. Данные осмотров при этом никуда не отправляются —
они живут в браузере пользователя.

**Можно сделать репозиторий приватным?**
На бесплатном тарифе GitHub Pages работает только для публичных репозиториев.

**Сколько это стоит?**
Бесплатно для публичных репозиториев: до ~1 ГБ на сайт и ~100 ГБ трафика в месяц — для одного приложения
это с огромным запасом.

**Работает ли без интернета?**
Установленное приложение — да: после первого открытия оболочка и библиотеки сохраняются на устройстве.
Открытие по ссылке в браузере без сети не сработает, офлайн-режим есть только у установленного приложения.

**Можно без GitHub?**
Да, подойдёт любой статический хостинг: [Netlify Drop](https://app.netlify.com/drop),
Cloudflare Pages, Vercel. Главное — адрес должен начинаться с `https://`, иначе камера и установка не работают.
