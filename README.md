# Электроосмотр

Мобильное веб-приложение для фотофиксации осмотра объектов: помещения, снимки, дефекты кабельных трасс и выгрузка готового отчёта одним ZIP-архивом.

Работает в браузере телефона и **устанавливается как обычное приложение**: иконка на главном экране, запуск без адресной строки, работа без интернета. Все данные (фото, описания, параметры) остаются на устройстве пользователя и попадают только в скачанный архив.

## Что внутри

- **Камера без ограничений по числу кадров.** Живое превью, затвор, фонарик, переключение камер. Если браузер запрещает встроенную камеру — автоматически включается системная, кадры всё равно сохраняются.
- **Описание дефекта сразу с помещением.** В поле уже стоит `Помещение №1: ` — дописываете только суть, и в отчёте видно, где дефект.
- **Автосохранение.** Весь осмотр пишется в IndexedDB сразу после изменений: можно закрыть страницу и продолжить позже.
- **Отчёт.** Excel-таблица с чек-листом видов работ + ZIP с папками фото по помещениям и дефектам.
- **Установка (PWA).** Manifest, service worker и офлайн-кэш: приложение работает в щитовой и подвале без связи.
- **Оформление** в стиле электролаборатории: тёмная тема, моноширинные подписи, светодиодные индикаторы.

## Структура

```
index.html               — само приложение
manifest.webmanifest     — описание для установки (имя, иконки, standalone)
sw.js                    — service worker: офлайн-режим
icons/                   — иконки 192/512, maskable, apple-touch, favicon
vendor/jszip.min.js      — библиотека ZIP (локальная копия)
vendor/xlsx.full.min.js  — библиотека Excel (локальная копия)
README.md                — это описание
ИНСТРУКЦИЯ.md            — как опубликовать на GitHub Pages
```

Если папки `vendor` нет, приложение попробует загрузить библиотеки с CDN — понадобится интернет только в момент выгрузки отчёта. Без `manifest.webmanifest`, `sw.js` и `icons/` приложение работает, но установка и офлайн-режим недоступны.

## Как запустить

### Вариант 1. По ссылке (рекомендуется)

Разместите содержимое папки на любом статическом хостинге — например, на GitHub Pages. Пошагово: см. [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

После публикации адрес будет таким:

```
https://<ваш-логин>.github.io/<имя-репозитория>/
```

Открывать нужно **в Chrome (Android) или Safari (iPhone)**, а не во встроенном браузере мессенджера.

### Вариант 2. Локальный файл

Можно открыть `index.html` прямо с телефона. Важное ограничение: браузеры запрещают встроенную камеру для локальных файлов (`file://`), поэтому съёмка пойдёт через системную камеру — по одному кадру за запуск. Полноценная непрерывная съёмка и установка работают только по `https://`.

## Требования

- Android 8+ / Chrome или Яндекс Браузер; iPhone — Safari 15+.
- Для отчёта нужно немного свободного места в браузере (фото сжимаются до 2000 px, ~200–400 КБ на кадр).

## Приватность

Приложение полностью клиентское: нет сервера, нет аналитики, фото никуда не отправляются. Отчёт собирается и скачивается на устройстве. На хостинге лежит только сам файл приложения.
